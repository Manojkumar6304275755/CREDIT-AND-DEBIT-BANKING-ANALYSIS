# Debit and Credit Banking Analysis | Excel, SQL, Power BI & Tableau

# Project Overview

The Debit and Credit Banking Analysis project focuses on analyzing banking transactions to understand credit and debit patterns, transaction trends, bank performance, customer behavior, and potential high-risk transactions.

This project covers 12 analytical questions and uses Microsoft Excel, SQL, Power BI, and Tableau to perform data analysis, calculate key performance indicators (KPIs), and create meaningful visualizations.

The primary objective is to transform raw banking transaction data into actionable insights that support better business understanding and data-driven decision-making.

# Project Objectives

- Analyze debit and credit transaction amounts.
- Calculate key performance indicators (KPIs).
- Compare transaction activity across banks and branches.
- Understand monthly transaction trends and distributions.
- Analyze transaction amounts by state, religion, product group, and customer type.
- Identify high-value, suspicious, and potentially high-risk transactions.
- Create interactive dashboards and clear visual reports.
- Apply data analytics techniques using multiple industry-relevant tools.

# Project Workflow

1. Data Collection: Import the banking dataset into Excel, SQL, Power BI, and Tableau as required.
2. Data Cleaning: Review missing values, duplicates, inconsistent formats, and data types.
3. Data Preparation: Organize columns and prepare the dataset for analysis.
4. SQL Analysis: Write queries to filter, group, aggregate, and compare transaction data.
5. Excel Analysis: Calculate KPIs and create summaries using formulas and Pivot Tables.
6. Power BI Development: Build data models, measures, charts, and interactive dashboards.
7. Tableau Development: Create individual worksheets and combine them into a dashboard.
8. Insight Generation: Interpret the results and identify important patterns in debit and credit transactions.
